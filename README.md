# Финансы

Приложение для учёта личных доходов и расходов: операции, счета, аналитика по статьям.
Учебный проект Школы мобильной разработки Яндекса, iOS.

## Возможности

- **Операции.** Список доходов и расходов за день, добавление, редактирование, удаление.
- **Счета.** Баланс, корректировка, несколько счетов, выбор основного. Баланс прячется по тряске устройства.
- **Аналитика.** Экран на UIKit: фильтры по типу, периоду, статьям и счёту, сортировка,
  круговая диаграмма по статьям и детализация с долями.
- **Офлайн.** Данные хранятся локально и показываются без сети; изменения, сделанные офлайн,
  отправляются на сервер при восстановлении связи. Пока приложение работает офлайн, над таб-баром висит плашка.
- **Оформление.** Светлая, тёмная и системная темы; тактильная отдача с переключателем;
  анимированная заставка со звуковым тактильным рисунком.
- **Безопасность.** Вход по четырёхзначному код-паролю и по Face ID / Touch ID,
  размытие экрана в переключателе приложений.
- **Языки.** Русский и английский, переключаются внутри приложения без перезапуска.
- **iPad.** Поддерживается, включая повороты экрана.

## Требования

- Xcode 26 или новее
- iOS 18.0+
- iPhone или iPad

## Запуск

### 1. Склонировать репозиторий

```bash
git clone https://github.com/KirillKrainov22/shmr-finance.git
cd shmr-finance/shmr-finance
```

### 2. Прописать токен

Приложение ходит в API `https://shmr-finance.ru/api/v1`, для запросов нужен персональный токен.
В репозитории его нет и быть не должно — файл с токеном в `.gitignore`.

Скопируй шаблон и впиши свой токен вместо `PASTE_YOUR_TOKEN_HERE`:

```bash
cp Config.example.xcconfig Config.xcconfig
```

```
// Config.xcconfig
API_TOKEN = ваш_токен
```

Файл `Config.xcconfig` подставляет значение в `Info.plist`, откуда его читает `Secrets.apiToken`.
Если токен не прописан, приложение упадёт при первом запросе с понятным сообщением — это сделано
намеренно, чтобы не ловить `401` на каждом экране.

### 3. Открыть и запустить

```bash
open shmr-finance.xcodeproj
```

Выбери схему `shmr-finance`, симулятор или своё устройство и запусти (`⌘R`).
Зависимости Xcode подтянет сам: `Lottie` скачается по ссылке из `Package.swift`,
локальный пакет `Utilities` уже лежит в репозитории.

Для запуска на своём устройстве понадобится подписать приложение: в настройках таргета,
вкладка *Signing & Capabilities*, выбери свою команду разработчика.

## Структура

```
shmr-finance/
├── Package.swift              манифест модуля приложения
├── Config.example.xcconfig    шаблон конфигурации с токеном
├── Info.plist
├── Sources/AppFeature/        весь код приложения
│   ├── App/                   запуск и сборка зависимостей
│   ├── Features/              сценарии операций, счетов, аналитики и настроек
│   ├── Data/                  сеть, хранилища и сервисы
│   └── Shared/                общие модели и UI
├── Utilities/                 локальный пакет с круговой диаграммой
├── shmr-finance/              таргет приложения: точка входа, ресурсы, строки
└── shmr-finance.xcodeproj
```

Код приложения собран в Swift-модуле `AppFeature`. Таргет iOS-приложения содержит точку входа и ресурсы. Пакет `Utilities` предоставляет диаграмму для аналитики.

Код экрана находится внутри его фичи. Например, в `Features/Transactions/TransactionsList` рядом лежат Assembly, Container, ViewModel, UseCase и Router. Верстка находится в `View/`. Assembly создаёт зависимости, Container управляет жизненным циклом экрана, ViewModel готовит состояние для View и вызывает UseCase. UseCase получает доступ к данным через внедрённые сервисы. Router передаёт события навигации.

## Хранение данных

Локальное хранилище работает на двух движках — SwiftData и Core Data. Движок переключается
в системных настройках iOS (Настройки → shmr-finance → Хранение данных); при смене данные
переносятся в новое хранилище при следующем запуске.
